## Current Projects

### BioLoop-Pi

**BioLoop-Pi** is a personal research project for developing a modular biosignal acquisition, processing, and closed-loop experimentation platform using a Raspberry Pi and microcontrollers.

The project follows the pipeline:

**Signal Acquisition → Data Transfer → Signal Processing → Machine Learning → Closed-Loop Feedback**

Current work focuses on establishing the embedded data pipeline between a **Raspberry Pi 5** and **Raspberry Pi Pico 2 W**, including simulated signal generation, serial communication, and data reception.

Future stages will progressively explore:

- biosignal acquisition and data logging
- real-time signal processing
- machine-learning-based signal interpretation
- closed-loop sensing and feedback
- neural signal acquisition concepts
- bioelectronic interface experiments

BioLoop-Pi serves as a practical engineering foundation for future work in neural interfaces and biohybrid systems.

---

### Neural Interface Signal Recovery

**Neural Interface Signal Recovery** is a computational modeling project exploring how changes in neural-interface conditions may affect recorded signal quality and how signal recovery can be quantified over time.

The project focuses on:

- numerical simulation
- baseline signal modeling
- interface degradation
- recovery dynamics
- signal-quality evaluation

The current model is intentionally simplified and is being developed as a foundation for more realistic modeling of **electrode–tissue interactions and neural-interface stability**.
